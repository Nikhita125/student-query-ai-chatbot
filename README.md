# Student Query AI Chatbot System

An AI-powered chatbot that helps students get answers to common college-related questions.

## Features

* Student Registration and Login
* AI-based Question Classification
* TF-IDF Text Vectorization
* Logistic Regression
* FAQ Management
* Chat History
* Admin Dashboard
* SQLite Database

## Technologies Used

* Python
* Flask
* Machine Learning
* NLP
* HTML
* CSS
* JavaScript
* SQLite
* Scikit-learn

## How AI Works

Student Question
↓
TF-IDF
↓
Logistic Regression
↓
Intent Detection
↓
Answer

## Main Queries

* Exams
* Courses
* College Timing
* Library
* Hostel
* Fees
* Attendance
* Placements

## How to Run

Install the required packages:

```bash
pip install -r requirements.txt
```

Train the model:

```bash
python train_model.py
```

Run the application:

```bash
python app.py
```

Open in browser:

http://127.0.0.1:5000
